# CareerPilot Marketing

Public marketing website for **CareerPilot by CodeBegun**.

## Production domain

`https://careerpilot.codebegun.com`

## Deployment

This repository is intended to be deployed as a static website from the `main` branch. The repository root contains `index.html`, so Hostinger can deploy the repository contents directly to the website document root (`public_html`).

## Brand

- Primary: `#051D64`
- Secondary: `#359AAD`
- UI icons: Bootstrap Icons
- Product: CareerPilot
- Parent brand: CodeBegun

## Funnel goal

The primary landing-page CTA is the free Career Readiness Check for B.Tech students, leading into CareerPilot membership conversion.
